# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.6.1 | yes |
| older   | no |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use [GitHub's private vulnerability reporting](https://github.com/Osyna/OpenInstaLink/security/advisories/new) or email
the maintainers (see the repository profile). Include what you found, how to reproduce it, and what an attacker
could do with it.

You can expect an acknowledgement within a few days. Once the issue is
confirmed we will agree a disclosure timeline with you and credit you in the
release notes unless you prefer otherwise.

## Scope

Vulnerabilities in this project's own code are in scope. Issues in third-party
dependencies should be reported upstream, though we are glad to hear about them
so we can pin or patch.
